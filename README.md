# Christianity, apparently.

Static source for [christianityapparently.com](https://christianityapparently.com/).

## Questions

The searchable library lives in `questions.html`. Each of the 50 questions also has its own generated page under `questions/`.

The single source of question content is:

```
questions-data.json
```

After editing that file, regenerate the standalone pages with:

```bash
node scripts/build-questions.js
```

The generated pages include their own canonical URL, social metadata, Article structured data, and related-question links.

When questions are added or removed, also update the searchable index and `sitemap.xml`.

## Site shell and build (read before editing headers or question pages)

Every page uses **one** shared header, generated by `scripts/shell.js` and injected between
`<!--SHELL:HEADER-->` markers by `scripts/build-shell.js`. Its styles live in `site-header.css`
and its mobile-menu behavior in `site-header.js`. **Never edit a page's header by hand.**
Homepage/Councils styling lives in `home.css`; interior pages use `styles.css`.

```bash
npm run build     # regenerate question pages, then apply the shared shell (idempotent)
npm run check     # build + fail if anything changed + static checks (links, anchors, JS, content rules)
npm run test:browser   # real-browser suite: 94 pages x 1440/768/390 (needs: npm i && npx playwright install chromium)
```

Edit the shared header in `scripts/shell.js` / `site-header.css`, then run `npm run build`.
